## Objective

I aimed to create a simple and neat Personal Resume Website. The objective of this project was to design a clean and structured CSS layout for the HTML personal resume website created during the HTML module. Building upon a foundational HTML structure, modern CSS concepts including custom Google Fonts, a cohesive color palette, structured selectors, Flexbox layouts, sticky positioning, smooth anchor scrolling, and responsive media queries were applied to create an accessible, visually appealing, and user-friendly digital portfolio.

I chose to design a simple, clean resume website rather than a complex one because my priority was to understand the fundamentals of how HTML and CSS work together, and a simpler structure helped me grasp those concepts effectively.
